**ApexSense** is an automated height measurement and statistical analysis system that connects hardware components with a modern Python GUI via serial communication. Designed as a functional exhibition product, it measures, records, and analyzes height data in real-time.

---

## 🚀 Features

* **Real-Time Serial Communication:** Interfaces directly with Arduino microcontrollers to capture live sensor measurements and transmit dynamic buzzer/LED status states.
* **Smart Measurement & Countdown:** Automatically detects users under the sensor, stabilizes measurements with countdown timers, and calculates statistical percentiles.
* **Advanced Data Visualization:** Integrated Matplotlib charts providing live point plots and frequency distribution histograms for collected datasets.
* **Data Management & Sets:** Create, rename, delete, and manage multiple measurement sets with local JSON persistence and export capabilities.

---

## 🛠️ Technologies & Components

* **GUI Framework:** CustomTkinter, Tkinter
* **Data & Visualization:** Matplotlib, Statistics module
* **Hardware Integration:** PySerial, Arduino, Ultrasonic/Distance sensors
